# Virtual Storage Allocation & Fragmentation Simulator

C++ engine (array + hand-built linked list, First/Best/Worst Fit) with a multi-page website:
landing, Learn, Simulator, Free list, Statistics, Compare.

    make gui          # build
    ./gui_server      # run (Windows: .\gui_server.exe), then open http://localhost:8080
    make test         # 41 automatic checks

Run `gui_server` from this folder. See GUI_STEP_BY_STEP_GUIDE.md for the member-wise steps.
