How it works

The page is only the screen. All the data-structure work happens in the C++ program running on this computer.

You send a request

“Allocate file D with 7 blocks.” The button calls the C++ program.

C++ picks a gap

First, Best or Worst Fit walks the linked list of free segments.

Both structures update

The array marks the blocks; the list shrinks or removes the node. Releases merge neighbours.

The page draws it

C++ answers with the new state and the page animates the change.
