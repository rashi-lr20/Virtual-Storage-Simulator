Definitions (for your report)

  • Free segment: a continuous run of free blocks. Each one is a node of the linked list.
  • Largest free segment: the biggest node. A contiguous request can only succeed if it fits in this one.
  • Fragmentation failure: total free blocks ≥ request, but the largest segment < request.
  • No-space failure: total free blocks < request.
  • Consistency check: checkConsistency rebuilds the free runs from the array and compares them with the list, node by node.
