How to read the results

  • Success: allocation requests that found a gap.
  • Failed (frag.): requests that failed although enough free space existed in total.
  • Avg frag.: the fragmentation value averaged over every step of the workload.
  • Time: spent inside allocate and release only; use it to compare strategies, not as an absolute number.
  • Try other seeds. One workload can be lucky or unlucky, so do not draw conclusions from a single run. Report what you actually see.
